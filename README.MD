# LIER
**"LIER so you don’t ever have to believe the liar again."**

LIER is a modular, artist-first infrastructure for running unforgettable events ~ with none of the bloat, middlemen, or platform overhead that dilute culture. Built from the ground up by people in the scene, for people in the scene.

---

##  Concept
> Born from the chaos of voice memos, IG rants, and community DMs. Trained on the outliers. Operates in the liminal.

LIER is:
- A backend scaffold for custom event logistics (ticketing, access, anonymity, analytics)
- A lightweight ML layer for reactive tooling (contextual prompts, moderation, language)
- A statement against the algorithmic monoculture ~ and a tool for building our own

We’ve been yearning. LIER just wrote it down.

---

##  Features
- **Custom Ticketing & Access**  
  Ditch the RA fees. Spin up event pages, QR codes, whitelist-only lists, and direct fan access in seconds.

- **Anonymous Messaging Layer**  
  Built on a real-time messaging API scaffold. Enables confessional prompts, crowd interaction, feedback loops ~ all without breaking the vibe.

- **Modular ML Hooks**  
  Train small language models on the outlier data that *actually* defines your scene ~ IG stories, party texts, rave reviews. Plug into moderation, feedback, or dynamic projections.

- **Performer-First Tools**  
  Make tech that uplifts artists, not flattens them. Access control, time slots, audio routing ~ LIER leaves the music untouched, but digitizes everything else.

- **Stripe-Integrated Payments**  
  Handle door splits, vendor cuts, artist pay, and tip jars. Transparent and fast ~ because tech should never be the reason someone isn’t paid.

---

##  Architecture
- **Backend**: Node.js + TypeScript scaffold using [Kysely](https://kysely.dev) for type-safe SQL
- **Messaging API**: Realtime WebSocket-based system inspired by in-house service layer
- **ML Interface**: Lightweight R wrappers + CLI for training on curated datasets
- **Frontend**: React Native (help wanted!)
- **Payments**: Stripe Connect + Webhooks
